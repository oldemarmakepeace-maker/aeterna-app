# Проект AETERNA: Life Assistant

> Премиальный PWA-ассистент по управлению жизнью для предпринимателей.
> Объединяет календарь, напоминания, трекер привычек и ИИ-аналитику продуктивности.

---

## Технологический стек

| Слой | Технологии |
|---|---|
| **Frontend** | Next.js 15 (App Router), Tailwind CSS, Framer Motion, Recharts |
| **Backend** | FastAPI (Python), SQLAlchemy 2.0, asyncpg |
| **БД и Auth** | Supabase (PostgreSQL). Миграции — через Supabase Dashboard |
| **Интеграции** | Google Gemini (STT + Intent Extraction) |

## Главные правила для ИИ-агентов

1. **Дизайн-код**: "Quiet Luxury" (Тихая роскошь). Строго следуй палитре и типографике, описанным ниже. Никаких стандартных ярких цветов Tailwind.
2. **Геймификация**: Используем систему бизнес-индексов и XP. Никаких эльфов и магии, только суровая аналитика продуктивности.
3. **Аналитика**: Отвечай пользователю строго по фактам. Тон — беспристрастный ассистент, без эмодзи и слов поддержки.
4. **Архитектура**: Строго следуй модульной архитектуре. Не пиши весь код в один файл. Backend: Routers → Services → Repositories.
5. **Типизация**: Все данные строго типизированы через Pydantic v2 (backend) и TypeScript (frontend).

## Геймификация: Индекс Продуктивности

### Терминология

| Термин | Описание |
|---|---|
| **XP** | Очки опыта, начисляемые за выполнение задач |
| **Капитализация** | Совокупный накопленный XP пользователя |
| **Баланс сфер** | 6-осевая радарная диаграмма жизненных категорий |
| **Бизнес-ранги** | Уровни прогресса на основе суммарного XP |

### 6 осей баланса (Radar Chart)

1. **Работа** (`work`)
2. **Здоровье** (`health`)
3. **Отношения** (`relationships`)
4. **Отдых** (`recreation`)
5. **Финансы** (`finance`)
6. **Рост** (`growth`)

Визуализация: Recharts `<RadarChart>` с `<PolarGrid gridType="polygon" />` и полупрозрачной медной заливкой (`copper-muted`).

### Типы задач и XP

| Тип | Выполнение | Пропуск / Срыв |
|---|---|---|
| **Рутина** (`routine`) | +5 XP × streak_mult | 0 XP (без штрафа) |
| **Стратегическая** (`strategic`) | +20 XP × streak_mult | −15 XP |
| **Hard Block** (`hard_block`) | +50 XP × streak_mult | −100 XP |

### Бизнес-ранги

| Ранг | Порог XP |
|---|---|
| Операционный | 0 — 499 |
| Тактический | 500 — 1 999 |
| Стратегический | 2 000 — 4 999 |
| Элита | 5 000+ |

### Математика

**Экспоненциальное затухание (Decay):**
```
V(t) = V₀ × e^(−λt)
```
- `λ = 0.05` — коэффициент затухания.
- `t` — дни без активности в категории.
- Минимум: `5.0` (не падает до нуля).

**Streak-множитель (сложный процент):**
```
multiplier = 1.0 + 0.1 × min(streak, 30)
```
- Максимум: `×4.0` при серии 30 дней.

## API-контракты (v1)

### Tasks
- `POST /api/v1/tasks` — создание задачи
- `GET /api/v1/tasks` — список (фильтры: status, category, date)
- `PATCH /api/v1/tasks/{id}` — обновление (смена статуса → триггер XP)
- `DELETE /api/v1/tasks/{id}` — удаление

### Calendar Events
- `POST /api/v1/events` — создание события
- `GET /api/v1/events` — список (фильтры: date, is_hard_block)
- `PATCH /api/v1/events/{id}` — обновление

### Analytics
- `GET /api/v1/analytics/productivity-index` — ProductivityIndex (6 осей + rank + xp)
- `GET /api/v1/analytics/xp-history` — лог XP-транзакций

### Auth (через Supabase)
- `POST /api/v1/auth/register` — регистрация
- `POST /api/v1/auth/login` — авторизация (JWT)
