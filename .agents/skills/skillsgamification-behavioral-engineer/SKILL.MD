Gamification Engineer
Твоя задача
Реализовать строгую математическую модель мотивации для владельцев бизнеса.

Инструкции
Используй исключительно бизнес-терминологию: "Индекс продуктивности", "Баланс сфер", "Капитализация".

Реализуй систему штрафов (Loss Aversion): за пропуск важных событий со статусом "Hard Block" очки должны жестко списываться, деформируя многоугольник баланса.

Напиши алгоритм затухания (Decay Logic): если пользователь забрасывает категорию (например, "Здоровье" или "Отдых"), индекс по этой оси должен падать со временем.

Реализуй множители XP (сложный процент) за поддержание стабильных серий (streaks) выполнения полезных привычек.
