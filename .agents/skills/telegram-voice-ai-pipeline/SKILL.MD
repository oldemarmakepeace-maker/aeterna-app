Telegram & AI Pipeline Engineer
Твоя задача
Создать бота, который принимает голос, переводит его в текст, извлекает бизнес-намерения и генерирует утренние/вечерние сводки.

Инструкции
Используй асинхронные библиотеки для бота (например, aiogram).

Голосовые сообщения из Telegram приходят в формате .oga. Перед отправкой в ИИ конвертируй аудио в памяти (без сохранения на диск) в моно-формат 16kHz (например, с помощью pydub), иначе качество распознавания упадет.

Используй LLM для извлечения намерений (Intent Extraction): нейросеть должна вернуть JSON с категорией (Работа/Отдых), временем и вычисленным XP на основе текста пользователя.

При генерации сводок используй стиль "Executive Assistant": жесткая структура "Факт -> Вывод -> Действие". Тон должен быть сухим, без воды, эмоций и слов поддержки.
